## 📖 1. О проекте

Данный проект представляет собой REST API (бэкенд) информационной системы (АРМ), разрабатываемой для автоматизации процессов учета участия студентов в олимпиадах и конкурсах профессионального мастерства.

**Основные возможности:**
*   **Управление пользователями:** создание ролей (admin, teacher, student) и профилей пользователей.
*   **Управление олимпиадами:** создание карточек олимпиад (название, даты, ответственный преподаватель).
*   **Учет участия:** запись студентов на олимпиады и отслеживание их результатов.
*   **Документирование:** автоматическая генерация Swagger/OpenAPI документации.

**Текущий этап разработки:** Реализовано ядро системы и основные сущности (роли, профили, олимпиады, участие). Ведется работа над JWT-аутентификацией и Django-фронтендом.

---

## 🛠 2. Стек технологий

*   **Язык программирования:** Python 3.10+
*   **Бэкенд (API):** FastAPI, SQLAlchemy (ORM), Pydantic (валидация), Alembic (миграции)
*   **База данных:** PostgreSQL (клиент-серверная СУБД)
*   **Аутентификация:** JWT-токены (в разработке)
*   **Тестирование:** Pytest, pytest-django, pytest-asyncio, httpx, pytest-cov

## 📂 3. Файловая структура проекта

Структура проекта строго соответствует модульному подходу, разделяющему зоны ответственности.

```text
curs_project/
├── app/
│   ├── api/
│   │   └── v1/                     # API версии 1
│   │       ├── auth_api_router.py  # Маршруты аутентификации
│   │       ├── profile_api_router.py # Маршруты для профилей
│   │       ├── role_api_router.py  # Маршруты для ролей
│   │       ├── olympiad_api_router.py # Маршруты для олимпиад
│   │       └── participation_api_router.py # Маршруты для участия
│   ├── controllers/                # Бизнес-логика (сервисы)
│   ├── core/                       # Ядро приложения
│   │   ├── config.py               # Настройки (чтение .env)
│   │   └── security.py             # Хэширование паролей, JWT
│   ├── db/                         # Слой работы с БД
│   │   ├── database.py             # Движок SQLAlchemy, Base
│   │   └── session.py              # Фабрика сессий
│   ├── models/                     # ORM-модели SQLAlchemy
│   │   ├── role.py                 # Модель Role
│   │   ├── profile.py              # Модель Profile
│   │   ├── olympiad.py             # Модель Olympiad
│   │   └── participation.py        # Модель Participation
│   ├── schemas/                    # Pydantic-схемы (валидация)
│   ├── main.py                     # Точка входа FastAPI
│   └── __init__.py
├── migrations/                     # Миграции Alembic
├── .env                            # Переменные окружения (не коммитится)
├── alembic.ini                     # Конфигурация Alembic
├── requirements.txt                # Зависимости проекта
└── README.md                       # Этот файл
```
